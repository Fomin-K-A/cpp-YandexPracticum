В уроке мы рассмотрели шаблон для функции Sum, складывающей два значения. Давайте решим более интересную задачу, увеличив количество аргументов и добавив к суммированию шаблоны функций для умножения и поиска максимума. Заодно создадим универсальную функцию DoOperation, которая будет выполнять для своих параметров указанную операцию. Тип операции задаётся перечислением OperationType.

// Сумма параметров.
template<typename T, typename S, typename U>
T Sum(T t, S s, U u);

// Произведение параметров.
template<typename T, typename S, typename U>
T Prod(T t, S s, U u);

// Определение максимума.
template<typename T, typename S, typename U>
T Max(T t, S s, U u);

enum class OperationType {
    OP_SUM,
    OP_PROD,
    OP_MAX,
};

// Вызов указанной функции для параметров t, s, u.
T DoOperation(T t, S s, U u, OperationType operation); 
Что нужно сделать
Для решения задачи придерживайтесь следующего порядка действий:
Напишите вариант шаблона Sum для трёх аргументов.
Реализуйте аналогичные шаблоны для произведения и поиска максимума. Функция произведения перемножает параметры, а функция максимума возвращает параметр с наибольшим значением.
Реализуйте функцию DoOperation с четырьмя параметрами: первые три — значения, над которыми нужно выполнить действие, а четвёртый — элемент типа OperationType.
В заготовке вам дана функция main, которая читает три значения типа int и использует их для проверки DoOperation, выводя полученные результаты.
