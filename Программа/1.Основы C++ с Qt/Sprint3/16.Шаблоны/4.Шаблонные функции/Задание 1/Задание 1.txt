Функция swap меняет два значения местами. Например, так можно поменять значения двух переменных:

int a = 15;
int b = 42;
std::swap(a, b);
assert(a == 42);
assert(b == 15); 
Что нужно сделать
Разработайте шаблонный вариант этой функции — Swap, который сможет менять местами значения переменных любого типа. Передача и получение двух значений происходят с помощью pair.
Использовать функцию можно будет так:

std::pair<int, int> p{3, 14};
std::pair<int, int> q = Swap(p);
assert((q == {14, 3})); 
Но вместо int можно использовать любой другой тип.
В заготовке вам дано:
Структура Point с перегрузками ввода, вывода и сравнения и функция для сравнения типа pair — они пригодятся для тестирования.
