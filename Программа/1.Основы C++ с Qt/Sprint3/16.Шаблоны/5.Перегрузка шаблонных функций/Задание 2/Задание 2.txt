Что тяжелее: унция перьев или унция серебра? Казалось бы, ответ лежит на поверхности, но всё не так просто. Для взвешивания серебра используются тройские унции, а для перьев — обычные, и в них разное количество граммов. Мы предлагаем вам написать функцию, которая всё-таки умеет сравнивать веса серебра и перьев. 
Количество унций будет записано в две разные структуры.

// Структура для хранения обычных унций.
struct Ounce {
    double count; // Количество унций, которое у нас есть.
    inline static double grams = 28.3495; // Сколько граммов в одной унции.
};

// Структура для хранения тройских унций.
struct OunceTroy {
    double count;
    inline static double grams = 31.1;
}; 
Что нужно сделать
Нужно написать перегруженную шаблонную функцию CompareOunces для сравнения этих структур.
Если переданные параметры имеют один тип (оба Ounce или оба OunceTroy), вызывается первый вариант функции, который просто сравнивает их значения по полю count.
Если параметры разные, используется вторая реализация, которая переводит оба значения в граммы и только потом выполняет сравнение.
Функция должна возвращать одно из трёх значений:
-1, если первое значение меньше;
1, если второе значение меньше;
0, если значения равны.
Ниже приведён пример работы функции.

assert((CompareOunces(Ounce{10}, Ounce{20}) == -1));
assert((CompareOunces(OunceTroy{20}, OunceTroy{10}) == 1));
assert((CompareOunces(Ounce{15}, Ounce{15}) == 0));

assert((CompareOunces(OunceTroy{10}, Ounce{10}) == 1));
assert((CompareOunces(Ounce{10}, OunceTroy{10}) == -1));
