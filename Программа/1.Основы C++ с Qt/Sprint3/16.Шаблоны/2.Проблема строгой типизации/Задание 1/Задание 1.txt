Что нужно сделать
В уроке мы разобрали, как создать класс для отрезка, концы которого могут быть заданы координатами типа int или double. Реализуйте аналогичный класс для случая, когда используется тип int64_t.
💡 Как правило, значение знакомого вам типа int занимает в памяти 4 байта, или 32 бита. Поэтому максимальное число, которое может в нём храниться, — 2 147 483 647 (2 в степени 31 минус 1). Попытка записать большее значение приведёт к переполнению.
Переменная типа int64_t занимает 8 байт, благодаря чему в ней можно хранить очень большие числа, длиной до 19 десятичных цифр.
Вам необходимо написать реализацию для класса Vector2DInt64, структуры PointInt64 и перегрузки вывода.

// Хранит координаты точки.
struct PointInt64 { };

// Выводит координаты точки.
std::ostream& operator<< (std::ostream &os, const PointInt64 &point);

// Хранит отрезок, заданный двумя точками.
class Vector2DInt64 { }; 
В заготовке вам дана вспомогательная функция PointInt64 GetPoint(std::istream& is), которая записывает координаты из ввода в структуру.
Также дана функция main, которая:
прочитает координаты двух точек;
создаст вектор, заданный точками, и рассчитает его длину;
выведет координаты точек и квадрат длины вектора.
