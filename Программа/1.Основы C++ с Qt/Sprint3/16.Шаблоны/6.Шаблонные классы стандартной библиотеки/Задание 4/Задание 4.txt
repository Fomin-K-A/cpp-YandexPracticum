Что нужно сделать
Напишите собственную реализацию класса optional. Добавьте в него методы для удобной работы:

template <typename T>
class Optional {
    ...
    
    // Возвращает true, если класс содержит значение.
    bool HasValue() const;
    
    // Возвращает значение.
    T GetValue() const;
    
    // Устанавливает новое значение.
    void SetValue(T value);
    
    // Удаляет значение.
    void Reset();
    
    ...
} 
Метод GetValue должен возвращать значение, хранящееся в классе.
Пример использования класса:

auto optional = Optional<std::string>();
assert(optional.HasValue() == false);

optional.SetValue("Say mew"s);
assert(optional.HasValue() == true);
assert(optional.GetValue() == "Say mew"s);
    
optional.Reset();
assert(optional.HasValue() == false); 
Стандартный optional можно использовать для класса, не имеющего конструктора без параметров. От вашего Optional такого не требуется.
