Что нужно сделать
В уроке было рассказано о структуре данных под названием «словарь», однако в нашей реализации доступ к элементам был возможен только по индексу. Особенность словаря в том, что нужное значение можно получить по ключу, причём каждый ключ хранится в единственном экземпляре.
Реализуйте метод SetValueByKey, который принимает два параметра: ключ key и значение value.

template<typename K, typename V> // Шаблон с типовыми параметрами K и V.
class VectorOfPairs {
    ...
    // Устанавливает значение по ключу.
    void SetValueByKey(const K& key, const V& value);
    
    ...
}; 
Если в векторе пар уже есть элемент с данным ключом, его значение нужно заменить на value. Если такого ключа нет, нужно добавить новую пару в конец вектора.
Юнит-тесты
Тест 1

VectorOfPairs<std::string, int> bank_accounts;

bank_accounts.SetValueByKey("Elon", 90000000);
bank_accounts.SetValueByKey("Bill", 10000000);
bank_accounts.SetValueByKey("Jeff", 99999999);
bank_accounts.SetValueByKey("Mark", 1234567);

using Vector = decltype(bank_accounts.GetUnderlying());
assert((bank_accounts.GetUnderlying() == Vector{
  {"Elon", 90000000},
  {"Bill", 10000000},
  {"Jeff", 99999999},
  {"Mark", 1234567},
}));

bank_accounts.SetValueByKey("Bill", 20000000);
bank_accounts.SetValueByKey("Mark", 98766767);
using Vector = decltype(bank_accounts.GetUnderlying());
assert((bank_accounts.GetUnderlying() == Vector{
  {"Elon", 90000000},
  {"Bill", 20000000},
  {"Jeff", 99999999},
  {"Mark", 98766767},
}));

bank_accounts.SetValueByKey("Larry", 111111111);
assert((bank_accounts.GetUnderlying() == Vector{
  {"Elon", 90000000},
  {"Bill", 20000000},
  {"Jeff", 99999999},
  {"Mark", 98766767},
  {"Larry", 111111111},
}));
