Что нужно сделать
Вам дан шаблон структуры для хранения треугольника.

template <typename T> 
struct Triangle {
  T A, B, C;
}; 
Элементы A, B, C могут быть любого типа — например, треугольник можно задать длинами сторон или координатами вершин. Используя данный шаблон, создайте три объекта структуры:
tr_int — треугольник, заданный тремя целыми числами.
tr_pair — треугольник, заданный тремя парами pair для хранения координат углов.
tr_point — треугольник, в котором координаты углов хранятся в Point.
Считайте, что в pair и Point можно записать только целые числа.
В заготовке вам даны перегрузки для ввода и вывода данных для сложных типов, чтобы упростить создание и вывод треугольников.
В функции main необходимо дописать определение трёх переменных. После этого функция прочитает значения для каждого треугольника и выведет их на экран.
Как будет тестироваться код
При проверке будет использоваться функция main, данная в заготовке.
Примеры
Пример 1
Входные данные
1 10 5
0 0 5 5 100 4
-5 -5 0 0 3 2 
Результат
1, 10, 5
(0; 0), (5; 5), (100; 4)
[-5; -5], [0; 0], [3; 2] 
Пример 2
Входные данные
5 5 5
1 1 2 2 3 3
1000 2000
0 0
0 0 
Результат
5, 5, 5
(1; 1), (2; 2), (3; 3)
[1000; 2000], [0; 0], [0; 0]
