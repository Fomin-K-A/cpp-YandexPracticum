Что нужно сделать
Мы с вами реализовали классы и структуры для работы с треугольниками. Теперь перейдём к кругу. Перед вами класс Circle, который позволяет задать круг с помощью координат центра и радиуса. 

class Circle {
public:
    Circle(PointInt center, int radius)
        : center_(center), radius_(radius) {}
    
private:
    PointInt center_;
    int radius_;
}; 
Давайте модернизируем его, превратив в удобный шаблон. Следуйте указанному порядку действий:
Преобразуйте класс в шаблон класса, чтобы координаты центральной точки Point могли быть любого типа (для этого нужно будет также заменить PointInt на шаблон Point).
Добавьте в шаблон второй параметр D для типа радиуса.
Напишите метод GetDiameter для получения диаметра круга. Тип значения диаметра должен совпадать с типом радиуса.
Юнит-тесты

Circle<int, int> c_int{{0, 0}, 10};
assert(c_int.GetDiameter() == 20);

Circle<int, double> c_int_d{{10, -10}, 11.11};
assert(c_int_d.GetDiameter() == 22.22);

Circle<double, int64_t> c_d_int64{{-0.1, -0.1}, 50000000000000};
assert(c_d_int64.GetDiameter() == 100000000000000);
