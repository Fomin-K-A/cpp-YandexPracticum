Доступ по индексу позволяет не только получать указанные поля класса, но и использовать его в качестве нехранящего контейнера — структуры данных, которая возвращает нужный элемент, «на ходу» рассчитывая его значение. 
Это полезно при работе с различными последовательностями. В задаче мы предлагаем вам таким образом реализовать класс для расчёта арифметической прогрессии.

Здесь a — элемент прогрессии, а d — разность прогрессии (её шаг).
Что нужно сделать
Дополните класс ArithmeticProgression, реализовав перегрузку для операции доступа по индексу. Операция должна возвращать указанный элемент прогрессии. Нумерация начинается с 1, и первый элемент равен начальному члену (start_).
Добавьте в перегрузку проверку корректности индекса: если номер элемента не положительный, завершите программу командой std::abort().

class ArithmeticProgression {
public:
    ArithmeticProgression(double start, double diff) : 
        start_(start), diff_(diff) {}

    ...

private:
    double start_;   // Начальный член.
    double diff_;    // Разность.
}; 
Пример использования класса:

// Задаём прогрессию с шагом 2 и начальным членом 1.
ArithmeticProgression progression(1, 2); 

for (int i = 1; i <= 10; i++) {
    std::cout << "Элемент_"s << i << " = "s << progression[i] << std::endl;
}
// Элемент_1 = 1 (так как 1 + 2 * 0 = 1).
// Элемент_2 = 3 (так как 1 + 2 * 1 = 3).
