В языке Python тоже есть последовательности. Однако их элементы можно получать, отсчитывая номера как с начала, так и с конца. Например, в последовательности из пяти элементов доступ к последнему будет по индексам 4 или -1, а к первому — по индексам 0 или -5. 
В C++ по умолчанию нет подобной возможности. Но с помощью перегрузок вы можете реализовать её.
Что нужно сделать
Вам дана заготовка класса IntArray. Добавьте этому классу перегрузку для доступа к элементам как по положительному, так и по отрицательному индексу.

class IntArray {
public:
    IntArray(std::vector<int> data): data_(data) {}
    
    void push_back(int value) {
        data_.push_back(value);
    }
  
private:
    std::vector<int> data_;
}; 
Обратите внимание, что при использовании положительных индексов нумерация элементов начинается, как обычно, с 0. Для отрицательных индексов она начинается с -1. Также добавьте в функцию проверку корректности индекса.
Пример использования класса:

IntArray arr({1, 2, 3, 4});
    
std::cout << arr[0] << std::endl;  // Первый элемент: 1.
std::cout << arr[-1] << std::endl; // Последний элемент: 4.
std::cout << arr[-2] << std::endl; // Предпоследний элемент: 3. 
Юнит-тесты
Тест 1

IntArray arr_1({1, 2, 3, 4});
assert((arr_1[0], 1));
assert((arr_1[1], 2));
assert((arr_1[-1], 4));
assert((arr_1[-2], 3));

IntArray arr_2({-17, 18, -19});
assert((arr_2[0], -17));
assert((arr_2[-1], -19));
assert((arr_2[-2], 18));
assert((arr_2[-3], -17));

IntArray arr_3({100, 200});
assert((arr_3[0], 100));
assert((arr_3[1], 200));
assert((arr_3[-1], 200));
assert((arr_3[-2], 100));

IntArray arr_4({15});
assert((arr_4[0], 15));
assert((arr_4[-1], 15));
