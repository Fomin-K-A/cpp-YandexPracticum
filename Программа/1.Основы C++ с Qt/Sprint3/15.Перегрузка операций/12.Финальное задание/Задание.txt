На протяжении темы вы решали несколько задач про рациональные числа — класс Rational. Напомним, что рациональное число задаётся дробями вида Числитель / Знаменатель, где числитель и знаменатель — целые числа (в нашем случае int) и знаменатель отличен от 0. 
В этом задании вам потребуется собрать вместе всё, что связано с этим классом, и создать полноценную библиотеку для удобной работы с рациональными числами.
Библиотеку, которую вы создадите, будет проверять ревьюер — она пригодится для финального проекта спринта.
Что нужно сделать
Создайте класс Rational, который хранит числитель и знаменатель дроби и содержит все необходимые операции, конструкторы и методы.
А именно нужно реализовать следующие операции:
Бинарные арифметические (+, -, *, /).
Присваивающие арифметические (+=, -=, *=, /=).
Операцию присваивания (=).
Унарные (+, -).
Ввода из потока и вывода в поток (<<, >>).
Проверки на равенство и трёхстороннего сравнения (==, <=>).
При выводе должна корректно читаться из потока дробь, заданная только одним целым числом (например, 42). Также если при выводе в поток знаменатель равен единице, то не нужно выводить его (нужно вывести 42 вместо 42 / 1).
Также класс должен содержать конструкторы, позволяющие конструировать его:
без аргументов (создаётся дробь 0/1);
из одного числа (числителя, знаменатель считается равным 1);
из двух чисел (числителя и знаменателя);
из другого объекта Rational по константной ссылке.
Помимо этого, реализуйте следующие публичные методы:
Rational Inv() const — преобразует дробь в обратную, то есть меняет числитель и знаменатель местами.
int GetNumerator() const — получить числитель.
int GetDenominator() const — получить знаменатель.
При любой модифицирующей операции нужно вызывать приватный метод Reduction для приведения дроби к несократимому виду. Напомним код этого метода:

void Reduction() {
    if (denominator_ < 0) {
        numerator_ = -numerator_;
        denominator_ = -denominator_;
    }
    const int divisor = std::gcd(numerator_, denominator_);
    numerator_ /= divisor;
    denominator_ /= divisor;
} 
Ограничения
Класс должен содержать только два поля типа int для числителя и знаменателя. Они должны быть приватными.
Класс должен всегда хранить приведённую дробь. Иными словами, если в конструктор передаётся дробь 2/-4 либо она получается при вычислениях, в классе должна сохраниться дробь -1/2. Этого позволяет добиться метод Reduction.
Знаменатель дроби должен быть всегда больше нуля. Если при создании дроби или при вычислениях получается отрицательный знаменатель, минус должен уйти в числитель.
