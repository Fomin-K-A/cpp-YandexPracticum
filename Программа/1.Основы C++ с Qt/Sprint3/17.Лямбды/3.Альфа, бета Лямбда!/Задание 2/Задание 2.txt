Откройте проект из папки sprint3/magic-buttons-2 вашего репозитория.
В качестве заготовки кода используйте ваше решение задачи предыдущего урока с настраиваемыми кнопками.
В прошлом уроке вы создали приложение с настраиваемыми кнопками. Теперь вам предстоит усовершенствовать это приложение и сделать его более гибким, используя лямбда-функции. Адрес страницы теперь можно будет вводить любой, а не выбирать из выпадающего списка. То же касается и открытия папки.
Для открытия произвольного URL или папки в файле functions.h определены функции OpenCustomUrl и OpenCustomDirectory, которые вам нужно будет вызывать из лямбда-функции.
Что нужно сделать
В этой задаче нужно изменить только код класса Setting, добавив в него две новые функции:
Открыть URL.
Открыть папку.
Эти функции нужно добавить в выпадающий список cb_action в конструкторе класса, используя метод addItem. Добавить их нужно после цикла, который добавит остальные пункты выбора.
В методе on_pb_save_clicked нужно поддержать выбор новых действий:
Скорректировать условие if, проверяющее корректность индекса.
Обработать два новых индекса и вызвать для них нужный сигнал.
При обработке новых действий нужно запросить у пользователя URL страницы или путь к папке. Это можно делать через статический метод QInputDialog::getText. В задаче используйте вариант этой функции из встроенной библиотеки моков:

#include <prac/QInputDialog>

// ...
