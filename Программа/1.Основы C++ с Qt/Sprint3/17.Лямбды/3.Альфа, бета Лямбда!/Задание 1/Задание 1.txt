Займёмся статистикой и, используя лямбда-функции, проанализируем строку с текстом. 
В файле main.cpp находится функция PrintStrStatistics, которая печатает статистику по количеству определённых символов в строке:
пробелов,
точек,
запятых.
Что нужно сделать
Сократите дублирование в коде. Не меняя сигнатуры функции PrintStrStatistics, создайте лямбда-функцию, которая будет считать количество указанных символов.
Лямбда-функция должна принимать один параметр: символ, который нужно считать.
Ограничения
Используйте для подсчёта лямбда-функцию с параметром типа char. Она должна захватывать str по ссылке.
Как будет тестироваться код
Будет проверено, что код работает так же, как изначальная функция, но в реализации используется лямбда.
Примеры
Пример 1
Входные данные
abcde ... ,,, 
Результат
Пробелов: 2, точек: 3, запятых: 3 
Пример 2
Входные данные
a 
Результат
Пробелов: 0, точек: 0, запятых: 0 
Пример 3
Входные данные
,a, 
Результат
Пробелов: 0, точек: 0, запятых: 2 
Пример 4
Входные данные
,a . . . 
Результат
Пробелов: 3, точек: 3, запятых: 1
