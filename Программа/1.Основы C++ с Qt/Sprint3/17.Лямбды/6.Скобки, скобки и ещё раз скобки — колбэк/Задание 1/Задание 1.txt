В этой задаче вы потренируетесь создавать компонент программы. На практике это очень частая ситуация: разные команды работают над программой одновременно. Это значит, что никто из них не видит всей картины целиком, не может запустить программу и протестировать её целиком. При этом важно сконцентрироваться на своей компоненте и чётко выполнять инструкции, чтобы поведение компоненты соответствовало ожиданиям.
Компания Sagittarius Ltd обрабатывает данные из космоса. Для этого используется детектор, разработанный компанией UFO, Inc., — класс UniverseListener. Этот детектор принимает сигналы и вызывает функцию обратного вызова при их обнаружении.
Информация о сигнале, выдаваемом детектором, задаётся следующей шаблонной структурой UniverseSignal:

enum class UniverseSignalType {
    UFO,                // НЛО.
    SUPERNOVA,          // Вспышка сверхновой.
    DYSON_SPHERE,       // Сфера Дайсона.
    GRAVITATIONAL_LENS, // Гравитационная линза.
};

struct SignalInformation {
    double signal_strength;  // Сила сигнала от 0 до 1.
    Coordinate coordinates;  // Сферические координаты точки.
};

template<UniverseSignalType type>
struct UniverseSignal {
    // Задаём статическое поле на основе шаблонного параметра.
    inline static UniverseSignalType signal_type = type;
    
    // Данные сигнала.
    SignalInformation info;
    
    // Информация, специфичная для этого типа сигнала.
    SignalPayload<type> payload;
}; 
Ваша задача — реализовать обработчик сигнала. За него будет отвечать класс SignalProcessor. Обработчик сигнала подключается к детектору и отправляет определённые сообщения, когда детектор сообщает о сигнале. Для отправки сообщений будет использоваться ещё одна готовая компонента – EmailSender.
Таким образом, ваша задача разработать класс SignalProcessor для взаимодействия между UniverseListener и EmailSender. В своём конструкторе он должен вызвать методы класса UniverseListener для задания обработчиков сигналов.
Обработчики сигналов должны отправлять электронные письма на указанные адреса. Для отправки писем используйте метод Send класса EmailSender. Этот метод принимает на вход следующие аргументы:
subject — тема письма;
body — текст письма;
address — адрес получателя.
Что нужно сделать
Реализуйте конструктор класса SignalProcessor. Он должен вызвать все четыре метода SetCallback* класса UniverseListener и передать в них функцию обратного вызова.
В качестве функции обратного вызова используйте шаблонную лямбда-функцию с
одним шаблонным параметром: UniverseSignalType type,
одним параметром в круглых скобках: полученным сигналом типа UniverseSignal<type>.
Реализуйте алгоритм работы лямбда-функции:
если сила сигнала signal_strength меньше значения 0.8, то игнорируйте такой сигнал;
иначе отправьте электронное письмо, воспользовавшись методом Send класса EmailSender.
Метод Send принимает четыре параметра:
subject (тема письма),
body (текст письма),
address (получатель письма),
attachment (приложение к письму).
В качестве attachment передайте значение payload сигнала. 
Параметр subject можно получить таким образом: std::string subject = "Обнаружен объект: "s + signal.payload.name.
Параметр address нужно определить исходя из типа сигнала:
Для типа UFO: ufo@secret-committee.gov.
Для типа SUPERNOVA: evacuation@transport-department.gov.
Для типа DYSON_SPHERE: alien-contacts@secret-committee.gov.
Для типа GRAVITATIONAL_LENS: astronomy@university.edu.
В качестве параметра body используйте следующий текст: «В области неба <координата 0>;<координата 1> обнаружен указанный объект. Сила сигнала: <сила сигнала>.».
Как будет тестироваться код
Запустится метод Run(), который будет вызывать установленную функцию в случае наступления события.
