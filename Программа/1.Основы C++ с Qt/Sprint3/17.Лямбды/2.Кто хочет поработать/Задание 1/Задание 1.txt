Латте, американо, капучино, какао и чай — напитки, которые может приготовить кофейный автомат. Каждый рецепт состоит из нескольких действий, они складываются в вектор.
Напиток наливается в чашку, которая задана такой структурой:

struct Cup {
    int coffee = 0;
    int cocoa = 0;
    int teabag = 0;
    int water = 0;
    int milk = 0;
    int steamed_milk = 0;
}; 
Программа приготовления довольно простая: она последовательно выполняет все шаги рецепта.

// Программа приготовления напитка.
int DoRecipe(const std::vector<RecipeAction>& recipe, Cup& cup) {
    int total_time = 0;
    
    for (const auto& action: recipe) {
        total_time += action(cup);        
    }
    
    return total_time;
} 
Тип напитка задаётся таким enum’ом:

enum class DrinkType {
    Latte, 
    Americano, 
    Cappuccino,
    Cocoa,
    Tea
}; 
Для добавления в чашку ингредиентов используются функции, которые добавляют одну порцию ингредиента (стандартная порция — 50 мл):
AddCoffee — добавить кофе;
AddWater — добавить воду;
AddMilk — добавить молоко;
AddSteamedMilk — добавить вспененное молоко;
AddCocoaPowder — добавить какао;
AddTeabag — добавить чайный пакетик.
В рецепте разрешается использовать только их.
Вот рецепты каждого из напитков:
Latte (латте) — кофе, молоко × 2, вспененное молоко.
Americano (американо) — кофе, вода × 2.
Cappuccino (капучино) — кофе, молоко, вспененное молоко.
Cocoa (какао) — какао, молоко × 4.
Tea (чай) — чайный пакетик, вода × 4.
Что нужно сделать
Через using определите тип RecipeAction — функциональный объект, который принимает ссылку на чашку (Cup) и возвращает int — время приготовления.
Напишите функцию CreateRecipe, которая составляет рецепт на основе функций добавления ингредиентов.
Если какой-то ингредиент нужен несколько раз, то соответствующую функцию нужно добавить в рецепт столько же раз.
Требования
Рецепт должен состоять только из функций, которые предоставлены в заготовке.
