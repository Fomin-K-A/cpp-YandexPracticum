Возьмите заготовку задания из папки sprint3/sort-words вашего репозитория.
Создайте графическое приложение, которое будет разбивать введённую строку текста на слова, сортировать их выбранным способом и выводить упорядоченную последовательность строк.
Процесс упорядочивания запускается при вводе новых символов в строку. Вид сортировки меняется переключателями.
Что нужно сделать
Реализуйте сортировку строк и выполняйте её при любых изменениях в интерфейсе программы.
Для ввода и вывода используйте элементы с типом QlineEdit:
le_unsorted — для ввода строки, которая разделяется на отдельные слова;
le_sorted — для вывода строки из отсортированных слов в соответствии с выбранным методом сортировки.
Способ упорядочить слова выбирается с помощью элементов QRadioButton:
rb_asс — по возрастанию, от А до Я.
rb_desc — по убыванию, от Я до А.
Регулирование сортировки с учётом регистра должно включаться с помощью элемента QCheckBox — cb_case. 
Как будет тестироваться код
Будет анализироваться выводимая строка текста в le_sorted.
