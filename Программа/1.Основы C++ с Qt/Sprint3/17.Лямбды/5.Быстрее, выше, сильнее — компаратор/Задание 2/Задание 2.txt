Помните задачу из предыдущего урока со списком учеников? Сейчас вам предстоит добавить функции-компараторы для сортировки списка по различным критериям.
Выявим лучших из класса!
Что нужно сделать
Реализуйте функции-компараторы:
1. CompareSurnameAsc — сравнение по фамилиям по алфавиту (от А до Я) с именованием;
2. CompareSurnameDesc — сравнение в обратном направлении (от Я до А);
3. CompareMeanScoreDesc — сравнение по среднему баллу по убыванию;
4. CompareBestScoreDesc — сравнение по количеству пятёрок в оценках по убыванию;
5. LexicographicalScoreCompare — сравнение по количеству пятёрок, а в случае равенства количества пятёрок — по среднему баллу.
Создайте функцию вывода на печать, которая принимает на вход список учеников, количество записей для печати и компаратор: 

template<typename Comparator>
void PrintTop(std::vector<Student> all_students, 
              std::optional<int> max_top, 
              Comparator comparator); 
 Функция должна:
Отсортировать список учеников, используя указанный компаратор.
Вывести заданное количество лучших учеников в std::cout. Количество задаётся параметром max_top типа optional<int>. Если в этом параметре передано значение std::nullopt, то нужно вывести всех.
Для вывода используйте operator<< из заготовки.
Требования
В функции PrintTop вместо алгоритма std::sort используйте алгоритм std::stable_sort. Принцип его использования такой же. Дело в том, что компаратор может не различать некоторые элементы. Например, компаратор, сравнивающий фамилии студентов, не различает студентов с разным именем, но одной фамилией. Их порядок при сортировке алгоритмом sort не будет определён. Использование stable_sort гарантирует, что эти элементы после сортировки будут идти в том же порядке, что и в исходном векторе.
В функциях CompareBestScoreDesc и LexicographicalScoreCompare используйте алгоритм std::count, чтобы посчитать количество пятёрок.
Как будет тестироваться код
Передадим данные в PrintTop и сравним ожидаемый вывод с полученным.
