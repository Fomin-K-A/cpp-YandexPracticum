Продолжим задачу из урока о расписании дел. Когда нужно успеть много, трудно разобраться, когда переходить от одного к другому. Предположим, у вас есть список дел и вы знаете, сколько занимает каждое из них. Например:
Завтрак — 30 минут.
Поиграть с котиком — 30 минут.
Дорога на работу — 30 минут.
Рабочий день — 480 минут.
Возвращение домой — 30 минут.
Ужин — 60 минут.
Если ваш день начинается в 9 утра, то расписание должно быть таким:
9:00 — Завтрак.
9:30 — Поиграть с котиком.
10:00 — Дорога на работу.
10:30 — Рабочий день.
18:30 — Возвращение домой.
19:00 — Ужин.
Каждое дело из распорядка дня мы задаём экземпляром такой структуры:

struct Task {
    std::string name; // Название задачи.
    int duration;     // Длительность задачи в минутах.
    int index; // Индекс очерёдности задачи.
}; 
Что нужно сделать
Напишите функцию std::vector<Task> BuildTimetableFor(const std::vector<Task>& source_tasks), которая составит расписание.
В первую очередь она должна отсортировать все задачи по следующему принципу:
Задачи располагаются по возрастанию индекса очерёдности.
Задачи с одинаковым индексом нужно отсортировать по имени.
Затем нужно вывести расписание в std::cout. Для этого в заготовке есть функция void PrintTask(const Task& task, int current_time). Она принимает задачу и параметр current_time — сумму длительностей всех предыдущих задач. Для первой задачи current_time будет ноль. Выведите все задачи в функции void PrintTimetable(const std::vector<Task>& tasks). Соедините вызовы BuildTimetableFor и PrintTimetable в функции void ProcessTimetable(const std::vector<Task>& tasks).
Как будет тестироваться код
Решение будет проверено на нескольких примерах. Код чтения и функция main уже даны в заготовке. Не меняйте их.
