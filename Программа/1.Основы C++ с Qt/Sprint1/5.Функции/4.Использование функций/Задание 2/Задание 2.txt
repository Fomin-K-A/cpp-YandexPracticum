Слева и справа получилась одинаковая запись, ведь и там и там мы используем десятичную систему счисления.
Что нужно сделать
Напишите функцию int StringToNumber(std::string s, int base), которая преобразует строку s, содержащую число, записанное в системе счисления base, в значение int. Функция должна поддерживать системы счисления с основанием от 2 до 36.
Для ввода-вывода используйте следующую заготовку функции main. Она считывает исходное представление числа в виде строки и число — основание системы счисления. Затем переводит строку в числовое представление и выводит результат в десятичной системе счисления.

int main() {
    std::string src_string;
    int src_base;

    std::cin >> src_string >> src_base;

    // Переводим число из строкового представления в системе 
    // счисления src_base в int.
    int number = StringToNumber(src_string, src_base);

    // Выводим число в десятичной системе счисления.
    std::cout << number << std::endl;
}

Ограничения
Функция StringToNumber не должна ничего выводить в stdout. Весь ввод-вывод должен размещаться в функции main.
Как будет тестироваться код
Тренажёр вызовет функцию StringToNumber с различными входными значениями и сравнит результат с ожидаемым.
Гарантируется, что система счисления находится в диапазоне от 2 до 36, а строка содержит символы, допустимые в этой системе счисления.
