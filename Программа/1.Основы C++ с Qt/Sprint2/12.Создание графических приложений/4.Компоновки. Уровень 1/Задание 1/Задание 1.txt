Подготовка формы:
В файл ресурсов добавьте все изображения фотоальбома.
Создайте отдельный префикс и добавьте в него изображения chevron_l.png и chevron_r.png. Это будут иконки кнопок.
На форме создайте две кнопки: btn_left и btn_right. У них настройте свойства icon и iconSize так, как показано на скриншоте:

При настройке icon воспользуйтесь опцией Выбрать ресурс… — вам предварительно нужно сохранить файл ресурсов, чтобы Qt Creator увидел вновь добавленные изображения.
В свойство кнопок styleSheet установите значение border:none. Оно позволит показать чисто графические кнопки.
Разместите на форме компоновщик, который будет помещать кнопки в нижние углы.
Удалите QLabel. Чтобы разместить его вне компоновщика, мы создадим его другим способом.
Таким образом, на форме должны остаться только две кнопки и, возможно, пружинки, которые вы добавите для правильного выравнивания.
Создание QLabel из кода
Перейдите в редактор кода. В приватную секцию класса MainWindow добавьте новое поле типа QLabel:

class MainWindow : public QMainWindow
{
...
private:
    // Передаём this (форму) в конструктор элемента.
    QLabel lbl_new_{this};
...
}; 
Чтобы это заработало, подключите #include <QLabel> в начале файла.
В cpp-файле замените ui->lbl_img на lbl_new_.
Внутри формы можно использовать этот виджет. Он находится вне компоновщика. Обратите внимание, что это не указатель: чтобы получить доступ к его полям, используется не стрелочка (->), а точка — lbl_new_.setPixmap(picture).
Метод SetFolder
Программа будет брать файлы из некоторой папки (даже если это папка в файле ресурсов).
Добавьте в класс формы новое поле QString current_folder_ и метод void SetFolder(const QString& d), который будет устанавливать это поле.
Добавьте новое поле int cur_file_index_. Оно будет показывать порядковый номер в папке изображения, которое сейчас показывается. Изначальное значение — 0. Метод SetFolder также должен сбросить это поле в 0 — при смене папки будем переходить к первому изображению.
Добавьте метод GetCurrentFile. Он должен возвращать название файла изображения на основе значений current_folder_ и cur_file_index_. Для реализации метода используйте QDir. Нужно прочитать список файлов директории current_folder_ и взять файл с номером cur_file_index_. Нужно обязательно проверить, что cur_file_index_ не меньше нуля и строго меньше количества файлов директории. Это можно сделать таким трюком:

// Сохраним количество файлов.
int total = int(list_files.size());

int file_index = std::min(cur_file_index_, total - 1);
file_index = std::max(0, file_index);

// Используем file_index, а не cur_file_index_.
return dir.filePath(list_files[file_index]); 
В методе SetFolder обновляйте изображение. Это можно сделать так: SetPixmap(GetCurrentFile());.
Метод SetFolder нужно вызывать из конструктора, передав папку из файла ресурсов таким образом: SetFolder(":/cats/images/");.
Переключение изображений
Кнопки влево и вправо должны менять cur_file_index_ и обновлять изображение.
На первом изображении должна стать неактивной кнопка влево, а на последнем — кнопка вправо. Для этого добавим метод UpdateEnabled. Вот его возможная реализация:

void MainWindow::UpdateEnabled() {
    // Количество изображений в папке.
    int max_images = QDir(current_folder_).entryList().size();
    
    // Устанавливаем активность кнопки «влево».
    ui->btn_left->setEnabled(cur_file_index_ > 0);
    
    // Устанавливаем активность кнопки «вправо».
    ui->btn_right->setEnabled(cur_file_index_ < max_images - 1);
} 
Метод UpdateEnabled нужно вызывать при нажатии кнопок, а также в методе SetFolder.
Учтите, что методы GetCurrentFile и SetFolder нужно сделать публичными (разместить в секции public:). Их будут проверять тесты. Остальные можете оставить приватными.
