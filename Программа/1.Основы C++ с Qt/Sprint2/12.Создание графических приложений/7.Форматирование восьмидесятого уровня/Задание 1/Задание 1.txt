Откройте проект из папки sprint2/format-date вашего репозитория.
Вам предстоит написать оставшуюся часть программы для форматирования даты.
Программа будет выводить дату в следующих форматах:
дд.мм.гггг (например, 01.07.2054).
мм/дд/гггг (например, 07/01/2054).
дд месяц гггг года (например, 01 июля 2054 года).
Ввод данных нужно будет организовать двумя способами:
установить маску формата 00.00.0000 в поле le_date с типом QLineEdit;
установить соответствующие ограничения в три поля QLineEdit для дня (le_day), месяца (le_month) и года (le_year).
Вывод данных:
на надпись lbl_format_type1 вывести дату в формате 1;
на надпись lbl_format_type2 — в формате 2;
на надпись lbl_format_type3 — в формате 3;
на надпись lbl_message вывести сообщение вида Это ? день в ???? году.
Сообщения об ошибках:
Если дата не существует (например, 40-е число 13-го месяца), вывести на lbl_message сообщение Такой даты не существует.
Если дата некорректная — сообщение Некорректная дата.
В обоих случаях нужно очистить надписи lbl_format_type1, lbl_format_type2, lbl_format_type3.
При изменении пользователем le_date нужно обновить текст в le_day, le_month и le_year. И наоборот тоже. Возникает циклическая зависимость, которую нужно корректно обработать.
Что нужно сделать
Ввод даты в le_date
В поле le_date вводится дата в формате дд.мм.гггг. Реализуйте слот изменения этого поля: on_le_date_textChanged.
В этом слоте полученная строка текста разбивается на день, месяц и год. Они записываются в поля le_day, le_month и le_year.
Можно использовать метод split, который разобьёт строку по разделителю:

// Такой split разбивает строку по точкам.
// Он возвращает значение типа QStringList,
// похожее на std::vector<QString>.
auto arr = ui->le_date->text().split(".");
if(arr.size() == 3) {
    ui->le_day->setText(arr[0]);
    ui->le_month->setText(arr[1]);
    ui->le_year->setText(arr[2]);
} 
Ввод даты в le_day, le_month и le_year
При изменении полей le_day, le_month и le_year должна обновляться выводимая информация. Для этого в соответствующих слотах вызывайте метод ShowFormattedDate(), который вы напишете далее. Метод будет обновлять le_date, поэтому необходим механизм разрыва циклической зависимости.
Валидация в методе ShowFormattedDate
С помощью этого метода проверьте валидность и корректность даты.
Если значение в одном из полей le_day, le_month или le_year не прошло валидацию, то вызовите SetError("Некорректная дата").
Прочитайте данные из le_day, le_month и le_year.
Чтобы преобразовать текст из поля ввода в число, используйте метод toInt:

int day = ui->le_day->text().toInt();
int month = ui->le_month->text().toInt();
int year = ui->le_year->text().toInt(); 
Вызовите метод DaysPerMonth, чтобы узнать, сколько дней в выбранном месяце выбранного года. Если номер дня больше полученного числа, то вызовите SetError("Такой даты не существует").
Методы форматирования
Реализуйте методы GetStrNumDays, GetFormatType1, GetFormatType2 и GetFormatType3. Они подготовят текст для надписей lbl_message, lbl_format_type1, lbl_format_type2 и lbl_format_type3 в нужном формате.
В этих методах используйте QString и его метод arg.
Вывод ShowFormattedDate
После валидации нужно вызвать методы, которые вы написали ранее (GetStrNumDays, GetFormatType1, GetFormatType2 и GetFormatType3) и поместить результат их работы в нужные надписи.
Как будет тестироваться код
Тесты Qt проверят, что вы выводите в lbl_format_type1, lbl_format_type2, lbl_format_type3 и lbl_message верные надписи, надписи обновляются при изменении введённых данных.
