Откройте проект из папки sprint2/photoalbum-4 вашего репозитория. В качестве заготовки возьмите своё решение задачи photoalbum-3.
В этой задаче вы добавите к фотоальбому несколько новых функций. Это будет возможность:
Показывать картинки не только из файла ресурсов, но и из любой выбранной папки с изображениями.
Включать и отключать режим «Поверх всех окон».
Настраивать работу приложения через контекстное меню, вызываемое щелчком правой кнопки мыши по окну.
Важно учитывать один момент: в папке могут быть не только изображения, но и посторонние файлы, которые нужно пропускать при просмотре. Ещё может быть так, что в выбранной папке вообще нет изображений. Тогда следует сделать обе кнопки неактивными.
Меню приложения будет таким:
Поверх всех окон (галочка)
Фото из файла ресурсов
Фото из выбранной папки
Закрыть программу
Программа показывает изображения из источника — некоторой папки. Это может быть папка ресурсов, как в предыдущей программе, или папка на диске. При изменении источника через меню нужно найти в выбранной папке первое изображение и отобразить его.
Если не удалось найти ни одного изображения в выбранном источнике, нужно заблокировать кнопки переключения и удалить изображение, если до этого оно находилось в QLabel.
Чтобы определить, является ли файл графическим, используется QPixmap. Файл считается файлом изображения, если из него удалось сконструировать корректный QPixmap:

QString path = GetImagePath();
// Конструируем QPixmap.
QPixmap pixmap{path};

if (pixmap.isNull()) {
    // Некорректное изображение.
} else {
    // Корректное изображение.
} 
Если поиск следующего изображения вызывает у вас затруднения, загляните в подсказки — там дана полная версия функции.
Для включения и выключения режима «Поверх всех окон» используйте метод setWindowFlags главного окна:

bool state = /* true — включить режим, false — выключить режим */;
setWindowFlags(windowFlags().setFlag(Qt::WindowStaysOnTopHint, state)); 
Что нужно сделать
Внесите следующие изменения в предыдущую версию фотоальбома:
Добавьте меню в соответствии с описанием выше.
Сделайте меню контекстным по клику на форму.
Реализуйте все эффекты меню.
Вот более подробное описание эффектов меню:
Поверх всех окон. Устанавливает или снимает флаг Qt::WindowStaysOnTopHint.
Фото из ресурсов. Устанавливает источник — папку ресурсов.
Выбрать папку. Показывает окно выбора папки. Если пользователь не отменил выбор, то устанавливает источник — выбранную папку.
Закрыть программу. Закрывает окно. Рекомендуется подключить к слоту через режим дизайнера.
При изменении источника нужно выполнить следующие действия:
Найти первое корректное изображение в папке. Отобразить его и запомнить номер этого изображения.
Если изображение не найдено, то нужно деактивировать кнопки переключения. А если найдено — активировать их.
При нажатии кнопок «Влево» и «Вправо» нужно:
Найти следующее или предыдущее корректное изображение в выбранном источнике.
Показать его и запомнить номер.
При этом возможна ситуация, когда в папке не оказалось изображений (например, пользователь удалил всё из папки). В этом случае нужно поступить аналогично выбору пустой папки.
Требования
Назовите QAction следующим образом:
Поверх всех окон — action_up_windows.
Фото из файла ресурсов — action_use_resources.
Фото из выбранной папки — action_choose_dir.
Вместо класса QFileDialog фреймворка Qt используйте его аналог prac::QFileDialog (требует #include <prac/QFileDialog>).
Этот класс подготовлен специально для задач Практикума. При запуске он будет работать точно так же, как и обычный QFileDialog, но в тестах будет вести себя по-другому, позволяя протестировать программу. Такие классы называются моками (от англ. mock — «подражание»). В тестах они эмулируют поведение настоящего объекта, но позволяют получить информацию о том, как объект был использован.
