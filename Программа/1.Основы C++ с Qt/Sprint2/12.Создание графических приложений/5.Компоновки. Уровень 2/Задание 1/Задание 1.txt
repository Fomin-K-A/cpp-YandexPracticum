Откройте проект из папки sprint2/grocery вашего репозитория.
На этот раз вы сделаете приложение для интернет-магазина. Оно позволит выбирать продукты, просматривать корзину и считать общую сумму заказа.
Эта программа многооконная. Она состоит из главного окна (selector.ui) и двух диалоговых окон.
Практически вся логика программы уже реализована в заготовке, вам нужно только построить компоновки. Единственное исключение: вам нужно будет реализовать работу кнопки «Корзина». Она показывает одно из двух диалоговых окон: корзины или ошибки.
Чтобы показать диалоговое окно, нужно создать объект этого окна и вызвать у него метод exec. Рассмотрим на примере окна ошибки — AddItemsNotification:

AddItemsNotification dialog{this};
dialog.exec(); 
Этот код нужно разместить в слоте, обрабатывающем нажатия на кнопку, чтобы диалоговое окно открывалось по нажатию на кнопку.
Что нужно сделать
В главном окне (selector.ui):
Виджеты продуктов скомпонуйте по сетке. Установите в компоновщике горизонтальные и вертикальные отступы.
Кнопки «Овощи», «Фрукты», «Напитки» и надпись «Добавить» скомпонуйте по вертикали. Добавьте в компоновщик пружинку, установите отступы.
Добавьте два предыдущих компоновщика в один горизонтальный компоновщик. Используйте отступ в 50 пикселей.
Нижние кнопки скомпонуйте по горизонтали. Средняя кнопка должна быть в два раза больше крайних.
Для всего окна используйте вертикальный компоновщик. Добавьте пружинку.


Компоновка главного окна
В диалоге корзины скомпонуйте виджеты по вертикали.


Компоновка диалога корзины
В диалоге ошибки:
Скомпонуйте виджеты по вертикали.
Добавьте пружинки, как на скриншоте.
Размеры пружинок должны соотноситься как 144 и 233, чтобы надпись располагалась по золотому сечению.
Измените sizePolicy элементов, чтобы они имели естественный размер и не растягивались.
Установите через контекстное меню горизонтальное выравнивание по центру.


Компоновка диалога ошибки
Открытие диалогового окна
В классе главного окна допишите код в слоте on_btn_cart_clicked. Вот что должен делать этот метод:
Получить список выбранных товаров вызовом метода GetCartItems.
Если список пуст, показать окно AddItemsNotification.
Если список не пуст, показать окно CartWindow.
При создании окна CartWindow нужно передать ему полученный список элементов:

// items – результат метода GetCartItems.
CartWindow dialog{items, this}; 
Ограничения
Меняйте только один метод. Остальные уже написаны.
Используйте те виды компоновщиков, которые указаны в условии.
Как будет тестироваться код
Тесты проверят, что вы везде используете правильные компоновщики.
Также тесты проверят свойства sizePolicy, веса и выравнивание объектов.
Тесты проверят наличие кнопки «Корзина».
Будет проверено, что в диалоговых окнах используется правильное форматирование.
