Откройте проект из папки sprint2/format-date-validators вашего репозитория.
В этом задании вам нужно добавить в программу валидаторы. Все поля программы независимы друг от друга. Вы настроите взаимодействие между ними в следующем уроке.
Чтобы показать некорректность полей числа, месяца и года, вы будете выделять их поля красными рамками. Это делается так:

elem->setStyleSheet("border:1px solid red"); 
Убрать выделение можно так:

elem->setStyleSheet("border:1px solid transparent"); 
Чтобы не дублировать код, напишите метод static void CheckValidity(QLineEdit* elem). Он проверит валидность поля для ввода и в зависимости от результата будет показывать или скрывать рамку.
Что нужно сделать
Добавьте для полей ввода ограничения:
Маску 00.00.0000 для поля ввода даты – le_date (маска добавляется через дизайнер — свойство inputMask).
Валидатор с допустимыми значениями 1–31 для поля ввода дня – le_day.
Валидатор с допустимыми значениями 1–12 для поля ввода месяца – le_month.
Валидатор с допустимыми значениями 1–9999 для поля ввода года – le_year.
Напишите метод static void CheckValidity(QLineEdit* elem), который будет снимать или добавлять красную рамку в зависимости от валидности ввода.
Вызывайте этот метод в слотах изменения для полей le_day, le_month, le_year.
Ограничения
В методе CheckValidity проверяйте валидность элемента, используя его метод hasAcceptableInput.
