Откройте проект из папки sprint2/calendar-horoscope вашего репозитория.
Вам предстоит сделать графическое приложение о календарях и гороскопах.
Программа должна предоставить возможность выбрать тип календаря и ввести год, для которого надо показать символ года. Если установлена галочка для ввода даты, то кроме символа года программа должна вывести на введённую дату один из двух гороскопов: либо по зодиакальному гороскопу, который состоит из 12 знаков зодиака, либо по гороскопу друидов, который состоит из 22 деревьев.
Поле для ввода года — QLineEdit с валидатором, позволяющим вводить только числа до 9999.
Для выбора типа календаря и гороскопа добавьте кнопки QRadioButton, которые объединены с помощью QGroupBox. Установите виджетам начальные значения.
Выбрать месяц можно из выпадающего списка, сформированного через дизайнер. Ввод дня осуществляется в поле с типом QSpinBox, через свойства добавьте ограничения на ввод интервала чисел (от 1 до 31).
По умолчанию ввод даты выключен. При снятии галочки «ввод даты» заблокируйте соответствующие элементы. 
При следующих событиях нужно обновить информацию:
изменение года,
изменение типа календаря,
установка или снятие галочки «ввод даты»,
изменение типа гороскопа,
изменение дня или месяца.
При решении задачи вам не придётся изучать гороскопы. Все данные можно получить из уже существующих функций, декларированных в файле magic_horoscope.h:

    // Получение символа года по восточному календарю.
    QString GetAnimalForEasternCalendar(int year);
    
    // Получение стихии года по восточному календарю.
    QString GetElementForEasternCalendar(int year);

    // Получение символа года по тибетскому календарю.
    QString GetAnimalForTibetanCalendar(int year);
    
    // Получение символа года по зороастрийскому календарю.
    QString GetAnimalForZoroastrianCalendar(int year);

    // Получение знака зодиака.
    QString GetZodiac(int day, int month, int year);

    // Получение названия тотемного дерева.
    QString GetTree(int day, int month, int year); 
Формат вывода
Формат вывода символа года (lbl_calendar)
Если год не выбран — Введите год.
Для тибетского календаря:
  гггг — это год ???.
  Используйте GetAnimalForTibetanCalendar.
Для зороастрийского календаря:
  гггг — это год ???.
  Используйте GetAnimalForZoroastrianCalendar.
Для восточного календаря:
  гггг — это год ???. Стихия/цвет — ???.
  Используйте GetAnimalForEasternCalendar и GetElementForEasternCalendar.
Формат вывода гороскопа (lbl_horoscope)
Если выбор даты отключён — Ввод даты отключён.
Если дата не существует (функция гороскопа вернула пустую строку) — Такой даты не существует.
Зодиакальный гороскоп:
  дд.мм — ваш знак зодиака ?? по зодиакальному гороскопу.
  Используйте GetZodiac.
Гороскоп друидов:
  дд.мм — ваше тотемное дерево ?? по гороскопу друидов.
  Используйте GetTree.
При выводе числа и месяца (дд и мм) дополняйте нулями до двух символов, год (гггг) дополнять не нужно.
Примеры
Если год — 2000, календарь — восточный, снята галочка с кнопки «ввод даты», то в интерфейсе:
В lbl_calendar выведено 2000 — это год Дракона. Стихия/цвет — металл/белый.
В lbl_horoscope выведено Ввод даты отключён.
Если год — 2000, календарь — зороастрийский, установлена галочка с кнопки «ввод даты», день — 4, месяц — февраль, гороскоп — друидов, то в интерфейсе:
В lbl_calendar выведено 2000 — это год Совы.
В lbl_horoscope выведено 04.02 — ваше тотемное дерево тополь по гороскопу друидов.
Что нужно сделать
Через дизайнер создайте интерфейс:

Если вы не хотите самоятоятельно создавать интерфейс, то используйте готовый ui-файл:
mainwindow.ui
В интерфейсе должны быть элементы со следующими названиями:
le_year (тип QLineEdit)
gb_calendar (тип QGroupBox) и в нём три элемента QRadioButton:
rb_tibetan с надписью «Тибетский»;
rb_zoroastrian с надписью «Зороастрийский»;
rb_eastern с надписью «Восточный».
gb_horoscope (тип QGroupBox) и в нём два элемента QRadioButton:
rb_zodiac с надписью «Зодиакальный»;
rb_druid с надписью «Друидов».
cb_is_date (тип QCheckBox).
sb_day (тип QSpinBox).
cb_month (тип QComboBox).
lbl_calendar (тип QLabel).
lbl_horoscope (тип QLabel).
В cb_month поместите названия месяцев через дизайнер. Для получения значения используйте метод currentIndex. Но учтите, первый элемент в списке имеет индекс ноль. Чтобы получить номер месяца нужно прибавить 1:

int month = ui->cb_month->currentIndex() + 1; 
Создайте слоты для сигналов:
нажатие переключателей rb_eastern, rb_tibetan, rb_zoroastrian, rb_zodiac, rb_druid — сигнал toggled(bool checked);
изменение статуса cb_is_date — сигнал toggled(bool checked);
изменение года — сигнал textChanged(const QString &arg1);
изменение дня — сигнал valueChanged(int arg1);
выбор месяца из выпадающего списка — сигнал currentIndexChanged(int index).
Добавьте метод обновления информации. Название метода выберите на своё усмотрение. Вызываете его из всех указанных слотов.
Этот метод должен обновить информацию в lbl_calendar и lbl_horoscope в соответствии с описанным Форматом вывода символа года и Форматом вывода гороскопа.
Как будет тестироваться код
Тесты Qt проверят, что вы выводите в lbl_calendar и lbl_horoscope верные надписи, надписи обновляются при изменении введённых данных.
Чтобы тесты прошли корректно, не используйте сигнал clicked для чекбоксов и радиокнопок. Используйте только toggled.
